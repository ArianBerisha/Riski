GITHUB UPLOAD INSTRUCTIONS

1. Extract RiskAI_GitHub_Upload_v2.2.zip.
2. Open the extracted RiskAI_GitHub_Upload_v2.2 folder.
3. Upload ALL CONTENTS of this folder to the ROOT of your GitHub repository.
4. Do not upload the ZIP itself as the website.
5. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. index.html, app.js, styles.css, sw.js, manifest.webmanifest and data/parameters.json must remain in the repository root structure shown here.
